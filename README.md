# ViaEnroll – Sistema de Inscripciones para Instituto Vía Diseño

Aplicación web desarrollada para **Instituto Vía Diseño** con el objetivo de automatizar y optimizar su proceso de inscripciones académicas. La plataforma permite la creación automática de grupos, asignación inteligente de horarios, registro de disponibilidad de profesores y gestión de solicitudes de cambio de materias.

## 🚀 Funcionalidades principales

- 🧾 **Automatización del proceso de inscripción**
- 🧑‍🏫 **Registro y gestión de disponibilidad de profesores**
- 📅 **Asignación automática de horarios**
- 🧠 **Creación automática de grupos**
- 🔁 **Gestión de solicitudes de cambio de materias**
- 🔐 **Inicio de sesión con seguridad usando bcrypt**
- 🌐 **Consumo de API oficial del Instituto Vía Diseño**
- 📄 **Interfaz con plantillas EJS y Bootstrap**

## 🛠️ Tecnologías utilizadas

- **Node.js** + **Express** (servidor web)
- **PostgreSQL** (base de datos relacional)
- **EJS** (motor de plantillas)
- **Bootstrap** (estilos responsivos)
- **JavaScript** (frontend dinámico)
- **bcrypt** (seguridad y hashing de contraseñas)
- **Postman** (pruebas de endpoints)
- **Git & GitHub** (control de versiones)
- **Arquitectura MVC**
